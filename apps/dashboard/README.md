# dashboard

Segnaposto. L'app verrà inizializzata nella Fase 6 di [new-plan.md](../../new-plan.md), dopo aver scelto il framework (Vite + React o Astro: vedi "Decisioni aperte").

Conterrà:

- **Area riservata**: CRUD di software, publisher (amministrazioni) e cataloghi; consultazione dei log; revisione delle richieste di onboarding e di terze parti.
- **Area pubblica**:
  - onboarding delle PA (flusso standard via PEC e fast onboarding via GitHub), che sostituisce `onboarding-italia`;
  - richiesta di inserimento di software di terze parti, che sostituisce la issue template `add_new_software` su GitHub.
